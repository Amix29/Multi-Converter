# Multi-Converter Branding Kit

Ce dossier rassemble les éléments de branding prêts à utiliser pour Multi-Converter.

Il constitue la source de référence du projet pour le logo, les tokens, les
guides, les modèles et les mockups. Les copies optimisées destinées au site
restent dans [`../site/public/`](../site/public/).

## Structure

`01_logo` contient les sources SVG du pictogramme et du lockup horizontal.

`02_guides` contient les règles d’usage du logo, la typographie, le ton rédactionnel et la checklist branding.

`03_tokens` contient les tokens CSS et JSON pour réutiliser les couleurs, rayons, ombres et polices.

`04_ui-kit` contient une page HTML de composants d’interface.

`05_templates` contient une brand board HTML et un template Open Graph SVG.

`06_mockups` contient un mockup produit HTML.

`07_iconography` définit le système d’icônes à développer.

## Direction principale

Multi-Converter doit rester propre, local, rassurant, papier, encre, minimaliste, moderne et légèrement brouillon de façon maîtrisée. Si un choix hésite entre spectaculaire et simple, choisir simple.
