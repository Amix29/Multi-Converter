# Provenance du système Multi-Converter

Les références visuelles et les ancres #c86a34 (clair) et #4d8445 (sombre) ont été validées par le mainteneur le 30 octobre 2026. Le kit de marque et le guide typographique versionnés fournissent les formes, la pile système sans-serif et les ombres décalées.

Les 56 tokens partagés sont explicites dans les deux modes. Les index natifs sont produits avec les fonctions de dérivation officielles Open Design. Le catalogue reste une démonstration ; aucune conversion ou OCR réelle ne lui est attribuée.
